# Tecmitón 2026 · Landing de apoyo

Página de apoyo de iniciativa personal para la campaña Tecmitón 2026 (Comunidad Tecmilenio 26, Carrera Virtual). No procesa pagos: todo dirige al formulario oficial del Tec de Monterrey.

## Publicar (GitHub Pages, solo la primera vez)
1. Settings del repo → Pages → Source: "Deploy from a branch" → Branch: main / (root) → Save.
2. La URL queda en: https://leonvelazquez-tecmi.github.io/tecmiton-2026/

## Actualizar cifras
Editar `datos.js` con los 4 valores oficiales de Carrera Virtual (procurado, meta, donantes, sello de hora). La página calcula porcentaje, brecha y donativos necesarios.
